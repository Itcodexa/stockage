# Guide d'utilisation du modèle d'import de Leads

## Vue d'ensemble

Ce modèle a été mis à jour pour correspondre à la liste de champs que vous avez fournie. Il est simplifié et contient les champs d'adresse et de description que vous avez ajoutés.

## Fichiers fournis

Format disponible pour l'import :

- lead_import_template.csv : Format CSV (compatible avec tous les outils)

## Champs obligatoires

Avant d'importer vos leads, assurez-vous de remplir les champs obligatoires suivants :

| Champ | Description | Exemple |
| --- | --- | --- |
| Company | Nom de l'entreprise | Acme Corporation |
| Last Name | Nom du prospect | Dupont |

Ces deux champs doivent impérativement être renseignés pour que l'import soit valide.
