# Projet fusion ActiveCampaign

## Contexte

Codexa utilise parallèlement Pardot et ActiveCampaign pour réaliser des automations mailing auprès de leur base de données. Cela génère non seulement un double coût, mais également beaucoup d’actions manuelles ce qui augmente considérablement le risque d’erreurs. 

## Besoin client

Utiliser Pardot pour centraliser toutes les automations mailing Codexa.

## Spécifications

### Fonctionnelles

Import manuel mensuel de l’intranet de l’ensemble de la base rédacteur (fichier excel)

Import manuel au fil de l’eau dès qu’un rédacteur nouvel entrant est identifié 

### Techniques

ActiveCampaign : [https://codexa.activehosted.com/app/overview](https://codexa.activehosted.com/app/overview)
Accès admin : oui
