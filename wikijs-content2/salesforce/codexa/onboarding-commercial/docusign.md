# Docusign

Après avoir créé le compte utilisateur sur le portail admin Docusign, il faut ajouter les accès SSO sur Salesforce.

Depuis le lanceur d’application, cliquer sur Afficher tout

![image.png](/docusign-image.png)

Sélectionner Configuration Docusign

![image.png](/docusign-image-1.png)

Sélectionner la rubrique gestion des utilisateurs sélectionner afin d’y ajouter le nouvel utilisateur à la liste des utilisateurs actifs.

![image.png](/docusign-image-2.png)
