# Hexagone

## Achat d’une nouvelle licence Hexagone

[https://appexchange.salesforce.com/appxMyAccount](https://appexchange.salesforce.com/appxMyAccount)

Cliquer sur l’avatar menu :

![](/hexagone-image4.png)

Cliquez sur My installs and Subscriptions :

![](/hexagone-image5.png)

Cliquez sur Manage Subscription :

![](/hexagone-image6.png)

Cliquez sur Edit :

![](/hexagone-image7.png)

Cliquez sur Users mettre à jour le nombre de licence puis cliquez sur Review Changes :

![](/hexagone-image8.png)

Le nombre de licence se met à jour instantanément sur Salesforce, il ne reste plus qu’à l’affecter à l’utilisateur.

## Installation d’une nouvelle licence Hexagone

Dans Configuration (Setup) taper Utilisateurs dans la barre de recherche rapide 

![image.png](/hexagone-image.png)

Cliquer sur le nom complet de l’utilisateur pour accéder à sa fiche 

![image.png](/hexagone-image-1.png)

Dans la rubrique Package gérés, cliquer sur attribuer des licences

![image.png](/hexagone-image-2.png)

sélectionner Hexagone Business dans Packages non attribués
