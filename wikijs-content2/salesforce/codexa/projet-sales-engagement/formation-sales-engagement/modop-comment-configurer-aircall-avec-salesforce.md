# Modop - Comment configurer Aircall avec Salesforce Einstein Conversation Insights ?

La fonctionnalité Einstein Conversation Insights de Salesforce permet aux utilisateurs de mieux analyser leurs appels pour obtenir des informations supplémentaires.

Pour configurer Aircall avec Einstein Conversation Insights, vous devrez :

- Installez et lancez l'application Voice Connector
- Connectez-vous en tant qu'utilisateur d'intégration dans Salesforce
- Générer une clé API Aircall
- Ajouter les identifiants nommés pour Aircall

Si vous n'avez pas encore configuré un autre connecteur, vous devez également suivre des étapes supplémentaires :

- Configurer l'application connectée
- Ajouter ECI en tant que fournisseur autorisé
- Configurer le site Salesforce
- Ajouter des informations d'identification nommées ECI
- Attribuer l'ensemble d'autorisations de l'utilisateur invité

## Installation et lancement de l' [application Voice Connector](https://appexchange.salesforce.com/appxListingDetail?listingId=e2716279-b205-426c-93dc-8681386adf91&tab=d)

Pour intégrer un connecteur vocal à Einstein Conversation Insights, veuillez suivre la documentation de Salesforce [**ici**](https://resources.docs.salesforce.com/latest/latest/en-us/sfdc/pdf/eci_connector_guide.pdf) .

## Création d'une clé API dans Aircall

Générez une clé API en accédant à la section « Intégrations & API » du Dashboard Aircall, en cliquant sur l’onglet « Clés API », et en générant la clé.

📚 [**Où trouver ma clé API Aircall**](https://support.aircall.io/hc/en-gb/articles/10375395181853-Where-to-find-my-Aircall-API-Key)

Copiez/collez votre ID API et votre jeton API quelque part pour une utilisation ultérieure, car vous ne pourrez plus voir votre jeton API.
