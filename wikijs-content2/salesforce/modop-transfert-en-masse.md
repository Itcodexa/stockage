# MODOP - Transfert en masse

Dans configuration, taper “Transférer en masse des enregistrements” dans la barre de recherche rapide.

Sélectionner : **Transférer des pistes** — Transférez plusieurs pistes d'un utilisateur à un autre

Url d’accès pour les pistes : [https://codexa.lightning.force.com/lightning/setup/DataManagementTransfer/page?address=%2Fp%2Fown%2FBulkTransfer%3Fent%3DLead](https://codexa.lightning.force.com/lightning/setup/DataManagementTransfer/page?address=%2Fp%2Fown%2FBulkTransfer%3Fent%3DLead)

![image.png](/modop-transfert-en-masse-image.png)

- **Critères de Pistes** :
    - Définir les critères pour sélectionner les pistes à réattribuer (par exemple, toutes les pistes dont Anaïs est la propriétaire ).

![image.png](/modop-transfert-en-masse-image-1.png)

- Cliquer sur rechercher
- Sélectionner toutes les pistes en cochant la case en haut à gauche

![image.png](/modop-transfert-en-masse-image-2.png)

- Cliquer sur le bouton transférer pour exécuter l’Assistant de Réattribution
